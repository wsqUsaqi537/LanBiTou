# 烂笔头

把要紧的事记下来，放在 Mac 桌面上，并在需要时提醒你。

## 下载与安装

[下载烂笔头 1.1.0（约 3.3 MB）](https://github.com/wsqUsaqi537/LanBiTou/releases/download/v1.1.0/LanBiTou-1.1.0.dmg) · [查看最新版本](https://github.com/wsqUsaqi537/LanBiTou/releases/latest)

支持 macOS 14 及以上的 Apple 芯片和 Intel Mac。

1. 下载并双击打开 DMG 文件。
2. 将“烂笔头.app”拖到“Applications”图标上。
3. 推出磁盘映像，从“应用程序”文件夹打开“烂笔头”。

升级时，先退出旧应用，再拖入新版并选择替换，原有事项会保留。

目前应用尚未经过 Apple 公证。如果首次打开被 macOS 阻止，请确认下载来源可信，然后前往“系统设置 → 隐私与安全性”，在“安全性”区域点击“仍要打开”。详见 [Apple 官方说明](https://support.apple.com/en-us/102445)。

## 记录与管理事项

- **新建**：点击“新建事项”，填写标题和备注，再点击“保存”。
- **编辑**：点击已有事项，修改后保存。
- **删除**：右键点击事项，选择“删除事项”，并确认删除。也可在编辑页面删除；删除后无法恢复。
- **筛选**：在左侧选择“全部事项”“今天截止”或“无期限”。

## 设置截止时间

新建或编辑事项时，开启“设置截止时间”，选择日期和时间。

- 选择具体时间，例如 10 月 8 日 14:00，事项到时自动移除。截止时间按 Mac 当前时区计算。
- 关闭“选择具体时间”，事项保留到截止日期结束，次日零点移除。
- 不设置截止时间，事项会一直保留，直到你手动删除。

应用退出期间，到期事项会在下次打开时清理；桌面小组件会隐藏已过期事项，显示更新可能稍有延迟。

## 设置提醒

1. 新建或编辑事项时，开启“提醒我”。
2. 选择提醒日期和时间，例如截止 14:00、提醒 12:00。
3. 保存事项，并在首次出现的系统提示中允许通知。

提醒时间须晚于现在；有截止时间时，提醒须早于截止时间。无期限事项也可以设置提醒。修改提醒会更新通知，关闭提醒或删除事项会取消通知。

已设置的提醒在应用退出后也可由系统发送。如果没有看到提醒，请检查“系统设置 → 通知 → 烂笔头”中的通知、横幅和声音设置，以及是否开启了专注模式。

## 放到桌面小组件

1. 先打开烂笔头，添加需要记录的事项。
2. 在桌面空白处右键，选择“编辑小组件”。
3. 搜索“烂笔头”，选择小、中或大尺寸，添加到桌面。

点击小组件可打开软件主页面。新增、编辑和删除事项后，小组件会同步更新，系统刷新可能稍有延迟。

## 数据保存

事项保存在当前 Mac，暂不支持 iCloud 和跨设备同步。
